# Tetris ойыны

Бұл жобада Python арқылы қарапайым Tetris ойыны жасалды. Ойыншы фигураларды төмен түсіріп, толық қатарларды жинайды. Қатар жиналған сайын ұпай көбейеді.

## Код туралы

- `main.py` ойынды іске қосады және негізгі циклді басқарады.
- `game.py` ойынның логикасын орындайды. Фигураны жылжыту, бұру, ұпай санау, пауза және қайта бастау осы файлда.
- `objects.py` ойын алаңы мен фигураларды құруға жауап береді.
- `settings.py` ойынның өлшемдері мен негізгі параметрлерін сақтайды.

Ойын Pygame кітапханасымен жасалған.

## Басқару

- Сол және оң жақ бағыттауыштар: фигураны жылжыту
- Төмен: фигураны тез түсіру
- Жоғары: фигураны бұру
- Space: фигураны бірден түсіру
- C: фигураны сақтап қою
- P: пауза
- R: ойынды қайта бастау

## Жобаға қатысушылардың жұмысы

- 1-қатысушы: ойынның негізгі логикасын жасау және фигуралардың қозғалысын реттеу.
- 2-қатысушы: ойын алаңы мен фигураларды жасау, олардың орналасуын тексеру.
- 3-қатысушы: ойынның терезесін, іске қосылуын және басқару батырмаларын баптау.
- 4-қатысушы: кодты тексеру, қателерді түзету және жобаны жинақтау.

Қатысушылардың аттарын өздеріңе қарай өзгертуге болады.
