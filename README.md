# Tetris — Neon Blocks

Небольшой Tetris на Python и Pygame. Здесь обычные правила собраны в отдельную игру с неоновым оформлением, музыкой и звуковыми эффектами.

Игровое поле — 10 на 20 клеток. Нужно собирать полные горизонтальные линии: за каждые 10 очищенных линий повышается уровень, а цель партии — дойти до 100. Есть три режима сложности, очередь следующих фигур, резерв, призрачная проекция места падения, комбо и статистика после игры. Лучший результат сохраняется в файл рядом с программой.

## Запуск

Установите библиотеку и запустите игру:

```bash
python -m pip install pygame-ce
python main.py
```

## Управление

- **← / →** — двигать фигуру
- **↓** — ускорить падение
- **↑** — повернуть
- **Пробел** — опустить фигуру сразу
- **C** — использовать резерв
- **P / Esc** — пауза
- **R** — новая партия
- **M** — звук вкл. или выкл.

В game.py находится логика партии, objects.py отвечает за поле и фигуры, settings.py хранит размеры и цвета, а effects.py создаёт звук и рисует блоки.
